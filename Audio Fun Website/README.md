# PulseCloud - Stealth Audio Prank Web Application

A realistic, modern SaaS product landing page configured to secretly play and continuously loop your local audio file the moment the user clicks anywhere on the page.

---

## 🚀 Quick Start

### 1. Place Your Audio File
Drop your desired audio file directly into this folder and name it:
- `audio.mp3` *(Recommended)*
- or `audio.wav`, `sound.mp3`, `prank.mp3`

### 2. Run Locally
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🤫 Secret Controls (Prankster Shortcuts)

- **Stop / Kill Audio**: Press <kbd>Escape</kbd> anytime, or double-click the **PulseCloud** logo in the top navbar.
- **Prank Settings Panel**: Press <kbd>Ctrl + Shift + P</kbd> or click the subtle `⚙️` icon in the footer to change the audio filename or adjust volume.
